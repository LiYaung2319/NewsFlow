# Verification Checklist

## Discovery

- [ ] 已读取项目入口、依赖和模块边界
- [ ] 已确认信息源类型：普通或复合
- [ ] URL/API 可访问，或已报告阻塞原因
- [ ] 已确认真实 HTML、JSON、RSS 或网络请求结构
- [ ] 已区分目标内容与导航、广告、推荐内容
- [ ] 已按用户要求完成试采集

## Confirmation

- [ ] 试采集结果已完整展示
- [ ] 已明确询问用户是否满足需求
- [ ] 用户已明确肯定
- [ ] 若用户否定，已重新探查并再次展示

## Implementation

- [ ] 复用了项目已有客户端和解析器模式
- [ ] 普通/复合分支与用户输入一致
- [ ] 复合板块有独立 URL、解析器、结果键和 source
- [ ] 标题、URL 校验和去重已实现
- [ ] 数量限制和排序规则已实现
- [ ] formatter、文档和测试按需同步

## Validation

- [ ] 真实网站链路验证通过
- [ ] 各板块未错误合并
- [ ] 语法检查通过
- [ ] 项目测试通过，或已说明没有测试
- [ ] `git diff --check` 通过

## Git

- [ ] 已检查工作区和远程差异
- [ ] 已排除日志、缓存、凭据和无关文件
- [ ] 已先展示规范的提交标题、正文和文件清单
- [ ] 已获得提交确认
- [ ] 已核对提交作者和作者日期
- [ ] 已获得推送确认
- [ ] 已核对远程分支状态

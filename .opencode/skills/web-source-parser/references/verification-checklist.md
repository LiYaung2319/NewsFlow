# Verification Checklist

## Discovery

- [ ] 已读取项目入口、依赖和模块边界
- [ ] 已确认信息源类型：普通或复合
- [ ] URL/API 可访问，或已报告阻塞原因
- [ ] 已确认真实 HTML、JSON、RSS 或网络请求结构
- [ ] 已区分目标内容与导航、广告、推荐内容
- [ ] 已按用户要求完成试采集

## Confirmation

- [ ] 试采集结果已完整展示
- [ ] 已明确询问用户是否满足需求
- [ ] 用户已明确肯定
- [ ] 若用户否定，已重新探查并再次展示

## Implementation

- [ ] 复用了项目已有客户端和解析器模式
- [ ] 普通/复合分支与用户输入一致
- [ ] 复合板块有独立 URL、解析器、结果键和 source
- [ ] 标题、URL 校验和去重已实现
- [ ] 数量限制和排序规则已实现
- [ ] formatter、文档和测试按需同步

## Validation

- [ ] 真实网站链路验证通过
- [ ] 各板块未错误合并
- [ ] 语法检查通过
- [ ] 项目测试通过，或已说明没有测试
- [ ] `git diff --check` 通过

## Final Report

- [ ] 已说明信息源标识和普通/复合类型
- [ ] 已说明页面/API、采集方式和各板块结果键
- [ ] 已列出实际修改、新增或删除的代码文件
- [ ] 已逐文件说明实现内容和项目影响
- [ ] 已列出验证命令、结果和证据
- [ ] 已明确说明未完成项和未执行验证
- [ ] 已明确说明已知风险
- [ ] 未生成提交日志或执行版本控制写操作
